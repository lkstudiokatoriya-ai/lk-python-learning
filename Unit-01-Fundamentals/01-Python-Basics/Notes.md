## 🚀 1. Hello World

### Definition
Hello World is a basic program used to display a simple message on the screen.

In Python, the `print()` function is used to display output.

### Syntax
`print("message")`

### Example
`print("Hello, World!")`

**Output:** `Hello, World!`

### Another Example
`name = "Lalan"`  
`print("Hello", name)`

**Output:** `Hello Lalan`

### Key Points
- `print()` is used to display output.
- Text is generally written inside quotes.
- Variables can also be displayed using `print()`.

## 💬 2. Comments

### Definition
A comment is text written in a program to explain the code. Python ignores comments during program execution.

### Syntax
`# comment`

### Example
`# This is a comment`  
`print("Hello, Python!")`

**Output:** `Hello, Python!`

### Comment with Code
`x = 10  # Store 10 in variable x`  
`print(x)`

**Output:** `10`

### Key Points
- `#` is used for a single-line comment.
- Comments are not executed by Python.
- Comments make code easier to understand.
- Comments help programmers explain their code.

## 📦 3. Variables

### Definition
A variable is a name used to store a value in a Python program.

### Example
`name = "Lalan"`  
`age = 18`  
`marks = 85.5`

Here:
- `name` stores a string value.
- `age` stores an integer value.
- `marks` stores a floating-point value.

### Displaying Variables
`name = "Lalan"`  
`age = 18`  
`print(name)`  
`print(age)`

**Output:** `Lalan` and `18`

### Multiple Variables
`a, b, c = 10, 20, 30`  
`print(a, b, c)`

**Output:** `10 20 30`

### Same Value in Multiple Variables
`x = y = z = 100`  
`print(x, y, z)`

**Output:** `100 100 100`

### Changing a Variable
`x = 10`  
`print(x)`  
`x = 20`  
`print(x)`

**Output:** `10` then `20`

### Checking Variable Type
`x = 10`  
`print(type(x))`

**Output:** `<class 'int'>`

### Key Points
- A variable is used to store a value.
- The `=` operator is used to assign a value.
- A variable's value can be changed.
- Multiple variables can be assigned in one statement.
- `type()` is used to check the data type.
