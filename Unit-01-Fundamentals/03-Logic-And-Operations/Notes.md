## 🔢 1. Arithmetic Operators

### Definition

Arithmetic operators are used to perform mathematical calculations in Python.

### Operators

`+` Addition  
`-` Subtraction  
`*` Multiplication  
`/` Division  
`//` Floor Division  
`%` Modulus  
`**` Exponentiation

### Example

`a = 10`  
`b = 3`

`print(a + b)` → **13**  
`print(a - b)` → **7**  
`print(a * b)` → **30**  
`print(a / b)` → **3.333...**  
`print(a // b)` → **3**  
`print(a % b)` → **1**  
`print(a ** b)` → **1000**

### Key Points

- `+` adds two values.
- `-` subtracts one value from another.
- `*` performs multiplication.
- `/` performs division.
- `//` performs floor division.
- `%` gives the remainder.
- `**` is used for power.

## 🔍 2. Relational Operators

### Definition

Relational operators are used to compare two values. The result is generally `True` or `False`.

### Operators

`==` Equal to  
`!=` Not equal to  
`>` Greater than  
`<` Less than  
`>=` Greater than or equal to  
`<=` Less than or equal to

### Example

`a = 10`  
`b = 5`

`print(a == b)` → **False**  
`print(a != b)` → **True**  
`print(a > b)` → **True**  
`print(a < b)` → **False**  
`print(a >= b)` → **True**  
`print(a <= b)` → **False**

### Key Points

- Relational operators compare values.
- The result is `True` or `False`.
- They are useful for checking relationships between values.

## 🧠 3. Logical Operators

### Definition

Logical operators are used to combine or modify conditions.

### Operators

`and` → True when both conditions are True.  
`or` → True when at least one condition is True.  
`not` → Reverses the Boolean result.

### Example

`a = 10`  
`b = 5`

`print(a > 5 and b < 10)` → **True**  
`print(a > 15 or b < 10)` → **True**  
`print(not(a > b))` → **False**

### Key Points

- `and` combines conditions.
- `or` combines alternative conditions.
- `not` reverses a condition's result.
- Logical operators work with Boolean values.

---

## 📝 4. Assignment Operators

### Definition

Assignment operators are used to assign values to variables and update their values.

### Operators

`=` → Assignment  
`+=` → Addition assignment  
`-=` → Subtraction assignment  
`*=` → Multiplication assignment  
`/=` → Division assignment  
`//=` → Floor division assignment  
`%=` → Modulus assignment  
`**=` → Exponent assignment

### Example

`x = 10`

`x += 5` → **15**  
`x -= 3` → **12**  
`x *= 2` → **24**  
`x /= 4` → **6.0**

### Key Points

- `=` assigns a value to a variable.
- Augmented assignment operators perform an operation and assign the result.
- Assignment operators make repeated calculations shorter.
